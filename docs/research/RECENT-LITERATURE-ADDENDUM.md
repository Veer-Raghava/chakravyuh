The existing audit covers Elliptic/Elliptic++, GCN/GAT, Inspection-L self-supervised GIN→RF, temporal/heterogeneous approaches, HGT/TGN/TGAT foundations and2026papers with protocol caveats. R25–R30 now add actual typed temporal, embedding-tree, anomaly and ownership-error experiments. Canonical event-time TGN, TGAT, HGT, sequenceTransformer fusion and contrastive pretraining remain **untrained candidates**, not implemented capabilities.

Suggested order follows unresolved questions rather than model novelty: capacity-matchedMLP; richer label-free neighborhood summaries; timestamped event encoder versus window GRU; past-only link/contrastive pretraining; encoder→LightGBM versus encoder→XGBoost; ownership-edge confidence ablation; typed attention only if mean aggregation leaves measurable errors. Use forward-only splits, repeated independent configurations, observed-coverage panels and fixed review budgets for every comparison. A conformal wrapper does not remove exchangeability/dependence assumptions or establish precision under simulator/network shifts.
