## One flag worth knowing (not a bug in the demo path)

`apps/drishti/src/adapter/format.ts` carries a comment saying the workstation shows identifiers
in full. The **API path** (what the demo serves) redacts at write time via `_redacted_address`
in `serialize.py`, so the demo never emits a full IP / address / txid — the "never emit a
complete identifier" rule holds where it counts. The full-identifier assumption only exists in
the committed dev **fixtures** (`VITE_SOURCE=fixtures`), which are synthetic and dev-only. Worth
tidying that comment sometime, but it doesn't affect the demo you'll show.
